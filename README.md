# DarkSider

DarkSider is a Flutter-based mobile app for learning **Dark Psychology** in **Hindi** and **English** with **Text-to-Speech (TTS)** and **Quizzes**.

## Features
- 90 Topics (Dark Psychology, Human Psychology, Manipulation, etc.)
- Bilingual: Hindi / English with language selector
- TTS with engaging male voice
- Learn section for each topic (paragraph)
- Quiz section with 90 questions per topic (8100 total)
- Login system (Firebase Auth)
- Simple, classy, and interesting UI
- Play Store ready: Privacy Policy, Terms, Settings, etc.
